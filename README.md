# SecureCast — OBS 개인정보 보호 필터 플러그인

방송 화면에 실수로 개인정보(주민번호·전화·이메일·카드번호 등)나 가려야 할 앱(카카오톡 등)이
노출되는 것을 **자동으로 가려 주는** OBS Studio용 네이티브 필터입니다.
모든 분석은 **인터넷 전송 없이 내 PC 안에서만** 이루어집니다.

> 핵심 아이디어 — **N-Frame Render Delay(프레임 지연 송출)**: 화면을 시청자에게 내보내기 직전
> 아주 잠깐 붙잡아 두고, 그 사이에 "가릴 게 있는지" 검사를 끝낸 뒤에야 내보냅니다.
> 그래서 팝업·알림이 갑자기 떠도 **검증되지 않은 화면은 송출되지 않습니다.**

---

## 1. 무엇을 해 주나 (주요 기능)

| 기능 | 설명 |
|------|------|
| **앱 화면 가리기** | 카카오톡·디스코드 등 지정한 앱 창이 화면에 보이면 그 영역만 자동으로 가림 |
| **개인정보 블러** | 화면 글자를 읽어(OCR) 주민번호·전화·이메일·카드·계좌·IP 등 패턴을 찾아 그 부분만 블러 |
| **지연 송출 보호** | 검증이 끝날 때까지 송출을 잠깐 지연 → 돌발 노출(팝업·알림)도 차단 |
| **보안 경광등** | 내 모니터에만 보이는 상태 표시등(평소 초록 / 위험 시 빨강). 시청자에겐 안 보임 |
| **게임 모드** | 게임 실행을 감지하면 무거운 글자 분석을 자동으로 꺼 CPU를 아낌(앱 가리기는 유지) |
| **패닉 버튼** | 단축키 한 번으로 화면 전체를 즉시 검정 처리 |

## 2. 설치하기 (GitHub에서 받아 쓰는 법)

> ⚠️ **Windows 전용** 플러그인입니다. (Windows 10 build 19041 / 2004 이상)
> OBS Studio **28 버전 이상**이 설치되어 있어야 합니다(권장 32.x).

설치 방법은 두 가지입니다. 대부분은 **방법 A(미리 빌드된 파일 받기)** 면 충분합니다.

### 방법 A — — GitHub Actions 빌드 결과물(아티팩트) 받아서 설치 (권장)
아직 정식 Release 가 없으므로, GitHub Actions 가 만든 빌드 결과물(아티팩트)을 받아 OBS 설치 폴더에 직접 복사하는 방식으로 설치합니다. 아래 경로의 기준이 되는 OBS 설치 폴더는 기본 설치 시 C:\Program Files\obs-studio\ 이며, 이 글에서는 이를 obs-studio\ 로 줄여 씁니다.

GitHub 저장소의 Actions 탭으로 이동합니다: https://github.com/jin030830/SecureCast/actions

성공한(초록 체크) 최신 빌드(Build Project 워크플로)를 클릭하고, 실행 페이지 맨 아래 Artifacts 에서 securecast-<버전>-windows-x64-<커밋해시> 를 내려받습니다.

GitHub가 아티팩트를 zip으로 한 번 더 감싸므로, 받은 zip 안의 zip까지 두 번 풀어야 할 수 있습니다.

압축을 끝까지 풀면 아래와 같은 securecast 폴더가 나옵니다:

securecast/
 ├─ bin/64bit/
 │    ├─ securecast.dll        ← 플러그인 본체 (dll)
 │    ├─ re2.dll               ← 정규식 런타임 (dll)
 │    └─ abseil_dll.dll        ← re2가 쓰는 런타임 (dll)
 └─ data/
      ├─ securecast_blur.effect   ← 셰이더 (effect)
      ├─ downsample.effect        ← 셰이더 (effect)
      └─ locale/
           └─ en-US.ini           ← 언어 파일 (ini)
위 파일들을 OBS 설치 폴더 안의 아래 위치에 각각 복사합니다.

① 플러그인 dll → obs-studio\obs-plugins\64bit\ securecast.dll 을 이 폴더에 복사합니다.

② effect 파일 → obs-studio\data\obs-plugins\securecast\ obs-studio\data\obs-plugins\ 안에 securecast 폴더를 새로 만들고, 그 안에 securecast_blur.effect 와 downsample.effect 를 복사합니다. → 이렇게 하면 obs-studio\data\obs-plugins\securecast\ 폴더가 새로 생깁니다.

③ 런타임 dll → obs-studio\bin\64bit\ re2.dll 과 abseil_dll.dll 을 이 폴더에 복사합니다. (OBS가 이 DLL들을 찾지 못하면 플러그인 로딩에 실패합니다. securecast.dll 도 함께 넣어 두면 더 안전합니다.)

④ ini(언어) 파일 → 아래 두 폴더 모두에 복사 en-US.ini 를 다음 두 곳 모두에 복사합니다.

obs-studio\obs-plugins\64bit\locales\
obs-studio\obs-plugins\data\obs-studio\locale\
OBS를 완전히 종료했다가 다시 실행합니다.

💡 re2.dll 과 abseil_dll.dll(위 ③ 런타임 dll)이 빠지면 OBS 시작 시 "Failed to load plugin" 오류가 납니다. 이 두 DLL을 꼭 넣었는지 확인하세요. 그래도 안 되면 이 두 DLL을 obs-studio\obs-plugins\64bit\ 의 securecast.dll 옆에도 같이 넣어 보세요. (백신이 경고할 수 있습니다 — 아래 8. 보안·백신 안내 참고)

### 방법 B — 직접 빌드해서 설치

소스를 직접 확인하고 빌드하고 싶다면 *7. 개발 환경 / 빌드 가이드* 를 따르세요.
로컬 빌드는 `%ProgramData%\obs-studio\plugins\securecast\` 로 **자동 배포**되므로 별도 복사가 필요 없습니다.

## 3. OBS에서 켜는 법

이 플러그인은 특정 **소스(예: 화면 캡처, 게임 캡처, 디스플레이 캡처)** 에 붙이는 **효과 필터**입니다.

1. OBS의 **소스 목록**에서 보호하고 싶은 소스(보통 "디스플레이 캡처")를 **우클릭 → 필터**.
2. 왼쪽 아래 **효과 필터** 영역의 **`+`** 버튼을 누릅니다.
3. **"SecureCast Privacy Masking"** 을 선택하고 이름을 지정합니다.
4. 추가되면 오른쪽에 설정 항목이 나타납니다. (아래 *4. 설정 항목* 참고)
5. 미리보기 화면에서 카카오톡 창을 띄우거나 주민번호 같은 텍스트를 보이게 해서,
   해당 부분이 자동으로 가려지는지 확인합니다.

> 여러 소스에 각각 붙일 수 있고, 패닉/OCR 토글 같은 단축키는 **모든 SecureCast 필터에
> 동시에** 적용됩니다.

## 4. 설정 항목 (필터 속성)

| 항목 | 설명 | 기본값 |
|------|------|--------|
| **보안 상태 경광등 표시** | 내 화면에만 보이는 상태 표시등. 끌어서 위치 이동, 우클릭으로 숨김 | 켜짐 |
| **일반 모드 차단 앱** | 위쪽 "앱 선택"에서 고른 앱을 "선택한 앱 추가"로 등록 → 그 창을 항상 가림 | 비어 있음 |
| **게임 모드 차단 앱** | 게임 모드일 때 **추가로** 가릴 앱 | 비어 있음 |
| **게임 모드 노출 허용 앱(화이트리스트)** | 게임 모드일 때 가리지 **않을** 앱(예: 게임 본체) | 비어 있음 |
| **보호 강도** | freeze(잠깐 멈춤)와 순간 노출 사이의 균형 선택 (아래 참고) | 균형(권장) |
| **Sticky 보호 지속 시간** | 창을 옮긴 뒤 블러를 얼마나 더 유지할지(ms). 길수록 이동 중 안전, 멈춘 뒤 늦게 풀림 | 1500ms |
| **OCR 입력 다운스케일** | 글자 분석 전 화면을 줄일지. "금지"면 작은 글씨까지 잘 잡지만 약간 느림 | 다운스케일 금지(권장) |
| **게임 모드 자동 진입** | 게임 실행을 감지해 자동으로 게임 모드로 전환(CPU 임계값·진입/해제 시간 조절 가능) | 켜짐 |
| **내 게임 목록** | 설치된 게임을 자동으로 찾아 등록(Steam/Epic 등). 게임 모드 판단에 사용 | 자동 검색 |

### "보호 강도" 세 가지

| 모드 | 동작 | 추천 상황 |
|------|------|-----------|
| **최대 보안** | 검증 끝난 안전한 프레임만 송출. freeze가 자주 보이지만 새 민감정보가 **단 한 프레임도** 노출 안 됨 | 금융·의료 시연 |
| **균형 (권장)** | 새 민감정보 등장 직후 최대 ~0.17초만 노출 허용, freeze 거의 없음 | 일반 스트리밍 |
| **부드러움 우선** | 최대 ~0.5초 노출 허용, freeze 사실상 0 | 게임·라이브 방송 |

## 6. 게임 모드는 어떻게 동작하나

게임을 실행하면 SecureCast가 이를 감지해 **자동으로 게임 모드로 전환**합니다.

- **글자 분석(OCR)을 끕니다** → CPU 사용을 줄여 게임 프레임을 보호합니다.
- **앱 가리기(블랙리스트)와 수동 블러, 알림 가리기는 그대로 유지**됩니다.
- 화이트리스트에 등록한 앱(게임 본체 등)은 가리지 않습니다.
- 게임을 끄면 잠시 뒤 자동으로 일반 모드로 돌아갑니다.

진입 조건(설치 게임 감지 + CPU 사용률)과 진입/해제 대기 시간은 설정에서 조절할 수 있습니다.

## 7. 개발 환경 / 빌드 가이드 (Windows)

본 프로젝트는 **CMake** + **C++20** 기반이며 빌드는 Windows에서 수행합니다.

### 요구사항
- Visual Studio 2022 (Desktop Development with C++)
- CMake 3.28 이상
- OBS Studio 32.x (의존성은 `buildspec.json`이 자동 내려받음)
- Windows 10 (build 19041 / 2004) 이상

### 빌드 (VS Developer Command Prompt에서)
```bash
# 1. CMake 설정 (Windows x64 프리셋)
cmake --preset windows-x64

# 2. 빌드
cmake --build --preset windows-x64
```

- 빌드가 끝나면 `%ProgramData%\obs-studio\plugins\securecast\` 로 **자동 배포**됩니다
  (`CMAKE_INSTALL_PREFIX` POST_BUILD 단계).
- DLL을 교체할 때는 **OBS를 먼저 종료**해야 합니다. 실행 중이면 DLL이 잠겨 복사가 실패합니다.
- 배포용 zip은 `cmake --install` 또는 CI(semver 태그 push)가 위 폴더 구조로 생성합니다.

### 소스 구조 한눈에 보기

| 파일 | 역할 |
|------|------|
| `plugin-main.cpp` | DLL 진입점 — OBS에 필터 등록 |
| `securecast-filter.cpp` / `.h` | 필터 코어 — 프레임 지연 링버퍼, 렌더, 마스킹 합성, 설정/단축키 |
| `ocr-engine.cpp` / `.h` | 화면 글자 인식(OCR) + 정규식 기반 개인정보 탐지 |
| `visual-tracker.cpp` / `.h` | OCR이 찾은 블러 박스를 매 프레임 따라다니게 하는 추적기(NCC) |
| `window_tracker.cpp` / `.h` | 차단 대상 앱 창의 화면 좌표 추적 |
| `win_event_listener.cpp` / `.h` | 창 생성/이동/숨김 등 OS 이벤트 즉시 감지 |
| `scroll_motion_hook.cpp` / `.h` | 스크롤/페이지 이동 입력을 미리 감지(순간 노출 방지용) |
| `overlay-window.cpp` / `.h` | 내 화면에만 보이는 보안 상태 경광등 |
| `game_sources/` | 설치된 게임 자동 검색(Steam/Epic/Battle.net/Riot/UWP 등) |
| `visible_subrects_cache.*` | 다른 창에 가려진 부분 계산 결과 캐시(성능) |

> 각 소스 파일 맨 위에는 "이 파일이 무엇이고 어떻게 동작하는지" 설명하는 한국어 주석 블록이
> 있습니다. 동작 흐름을 빠르게 파악할 때 그 블록부터 읽으면 됩니다.

## 8. 보안 · 백신 안내 (Security / Antivirus Notice)

SecureCast는 동작 특성상 일부 백신·보안 솔루션이 **오탐(false positive)** 으로 경고할 수 있습니다.
아래는 그 이유와 투명성 안내입니다.

**왜 오탐이 날 수 있나 (모두 정상 기능 수행을 위한 것):**
- **전역 입력 훅**(스크롤/모션 감지) 및 **창 이벤트 훅**(창 생성/이동/최소화/포그라운드 감지)
  — 가려야 할 창과 화면 변화를 추적하기 위함.
- **창·프로세스 열거 및 레지스트리 읽기** — 차단 대상 앱 및 게임 런처(Steam/Epic 등)
  자동 인식을 위함.
- **미서명(unsigned) DLL** — 코드 서명 인증서 미적용 시 휴리스틱 백신이 경고하기 쉬움.

**투명성 보장:**
- **소스 전체 공개 (GPLv2)** — 모든 동작을 코드로 검증할 수 있습니다:
  `https://github.com/jin030830/SecureCast` (배포 태그 기준).
- **모든 처리는 로컬에서만** 이루어집니다. 네트워크 통신·데이터 외부 전송 코드가 **없습니다**.
- **재현 가능한 빌드** — GitHub Actions(CI)가 동일 산출물을 생성합니다.

**권장:** 백신이 격리하면 설치 폴더(`%ProgramData%\obs-studio\plugins\securecast\`)를 예외로
추가하거나, 위 소스로 직접 확인 후 허용해 주세요. 신뢰가 중요하면 직접 빌드해 사용하실 수 있습니다.
